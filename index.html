Oyunları Türkçeye çeviren bir yerelleştirme aracı. WWE 2K26'nın kodlanmış metin dosyası formatını çözdüm ve kendi dosya yazıcımı geliştirdim. Çeviriyi bilgisayarımda çalışan yerel bir dil modeli yapıyor; ardından sözlük, yer tutucu, Türkçe büyük harf ve kalıntı İngilizce kontrollerinden geçiyor.

A localization tool that translates games into Turkish. I decoded WWE 2K26's encoded string file format and built my own file writer. A local language model on my own machine does the translation; the output then passes glossary, placeholder, Turkish casing and leftover-English checks.

  • ~1,2M kelime, tamamen yerelwords, fully local
  • ~15 saathours tam oyun çevirisifor the full game

Nasıl çalışıyorumHow I work

Modern araçlarla, kendi kurallarımlaModern tools, my own rules

Claude Code gibi yapay zeka destekli geliştirme araçlarını iş akışımın doğal bir parçası olarak kullanıyorum. Mimariye, önceliklere ve kaliteye ben karar veriyorum. Kendi kalite kurallarım var: kanıt olmadan "bitti" denmez, var olmayan fonksiyon kullanılmaz, kök neden bulunmadan hata düzeltilmez.

I use AI-assisted development tools such as Claude Code as a natural part of my workflow. I decide the architecture, the priorities and the quality bar, and I work by my own quality rules: nothing is "done" without evidence, no calls to functions that do not exist, no fix before the root cause is found.

ÖlçerekBy measuring

Bir değişikliğin işe yaradığını ölçmeden kabul etmiyorum. Test olmayan projelerde kendi kontrol araçlarımı kuruyorum; örneğin Lua kodunu var olmayan fonksiyonlara karşı otomatik tarayan bir kontrol.

I do not accept a change until I have measured that it works. Where a project has no tests, I build my own checks, such as one that scans Lua code for calls to functions that do not exist.

Hızlı öğrenerekBy learning fast

Bu sayfadaki işlerin çoğunu, başlamadan önce bilmediğim alanlarda yaptım: dosya formatı çözme, yerel dil modelleri, istatistiksel modelleme, 3D. Yeni bir ekibe katılırsam o ekibin araçlarını aynı hızla öğrenirim.

I did most of the work on this page in fields I did not know before I started: file format decoding, local language models, statistical modelling, 3D. If I join a new team, I will learn its tools at the same pace.
